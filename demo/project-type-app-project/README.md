# project-type-app-project (demo fixture)

Dummy project used only to exercise the `project-type-app` block's
`audit-docs` and `adr-cleanup` skills against real files. It is
intentionally incomplete — it ships `README.md`, `docs/adr/`, and
`docs/requirements.md`, but deliberately omits `docs/architecture.md`,
`docs/user-manual.md`, `docs/developer-guide.md`,
`docs/build-and-release.md`, and `docs/testing-strategy.md`, so that
`/audit-docs` has something real to flag as missing. See `demo/README.md`
for how to use it.
